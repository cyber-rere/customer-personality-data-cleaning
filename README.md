# Customer Personality Data Cleaning
## Project Overview
This project focuses on cleaning and preparing the Customer Personality Analysis dataset for analysis.

## Data Cleaning Tasks
- Handled missing values
- Removed duplicates
- Standardized categorical variables
- Converted date columns
- Created Age feature
- Detected and analyzed outliers
- Removed unnecessary columns

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset
Customer Personality Analysis Dataset from Kaggle.

## Key Insights
- Income contains a few high-income outliers.
- Several categorical inconsistencies were corrected.
- A small number of unrealistic age values
